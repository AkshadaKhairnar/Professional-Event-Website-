🎉 BE EVENTFUL 🎉

🌟 About the Project

BE EVENTFUL is a dynamic platform designed for organizing and managing professional events, exhibitions, and conferences. It provides an immersive experience integrating strategy, creativity, and technology to create unique and engaging events.

🚀 Features

🎨 Responsive Design: Built with Bootstrap 5 for a seamless experience across all devices.

🎭 Event Management: Various event categories like Conferences, Exhibitions, Product Launches, Workshops, and Visits.

🎞️ Automatic Slideshow: A JavaScript-powered carousel displaying event images.

📝 User Registration: Modal-based form submission for event signups.

📚 Interactive Sections: FAQ accordion, team details, and event descriptions.

📩 Newsletter Subscription: Collects user emails for updates.

🗺️ Embedded Map & Video: Location integration and promotional video embedding.

🛠️ Technologies Used

🏗️ HTML5 & CSS3 for structure and styling

🎨 Bootstrap 5 for responsive design and UI components

🖥️ JavaScript for interactivity and slideshow effects

🌍 Mapbox API for mapping features

🎥 YouTube Embedded API for video content

🏁 Installation & Usage

Clone the repository:

git clone https://github.com/your-username/BE_EVENTFUL.git

Navigate to the project directory:

cd BE_EVENTFUL

Open index.html in your preferred browser.
